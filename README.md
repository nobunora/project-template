# Project Template

This folder is a language-neutral starter for new projects.

Use it as a copy-on-create base when you want a fast, disciplined starting point with short rules, clear boundaries, and a predictable verification flow.

## First Reads

1. Read `AGENTS.md`.
2. Read `docs/00_index.md`.
3. Open one category index.
4. Open only the files you need.
5. Use `rg` before full-file reads.

## Standard Shape

- `src/` for source code
- `tests/` for focused tests
- `scripts/` for automation
- `docs/` for rules, templates, and project notes
- `docs/records/` for short milestone records when the project keeps development logs

## Standard Script Intent

- `doctor` for environment sanity checks
- `check` for quick local verification
- `typecheck` for static checks
- `test` for unit and integration tests
- `build` for production packaging
- `release:check` for serial preflight before release

## Included Guidance

- design and responsibility boundaries
- naming and contract stability
- test coverage and verification order
- safety and poka-yoke rules
- code review checklist
- reporting template
- development playbook for phase-based work
- refactor and release guardrails
- milestone and development record format
